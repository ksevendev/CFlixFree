O **K'Seven Stream** é uma plataforma de streaming web moderna, leve e responsiva, desenvolvida inteiramente com HTML5, Tailwind CSS e JavaScript puro (AJAX). O projeto consome dinamicamente dados de séries e filmes cadastrados em um arquivo **JSON externo** e integra-se diretamente com a **SuperFlix API** para reprodução de conteúdos.

---

## ✨ Recursos Principais

- 🎬 **Catálogo Dinâmico via JSON**: Adicione ou remova filmes e séries facilmente editando apenas o arquivo `catalogo.json`.
- 🔄 **Seletor Inteligente de Temporadas e Episódios**: Navegação fluida integrada com a SuperFlix API.
- 📱 **Design Responsivo & Dark Mode**: Interface futurista estilizada com Tailwind CSS, focada em uma experiência imersiva para mobile, tablets e desktops.
- ⚡ **Hospedagem Gratuita**: Pronta para rodar direto no **GitHub Pages** sem necessidade de servidores backend.
